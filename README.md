## How to Run

### Entry Point
* **Main Class:** `src/ui/MainFrame.java` (`ui.MainFrame`)

---

### Option 1: Using an IDE (VS Code, IntelliJ, Eclipse)
1. Open the project root folder (`computer-lab-reserve-system`) in your IDE.
2. Navigate to `src/ui/MainFrame.java`.
3. Click the **Run** button above the `main` method.
